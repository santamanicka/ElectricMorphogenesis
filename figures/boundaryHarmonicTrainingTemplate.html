Training the Ring

The Tilted Dial described ring codes by their harmonics: the dial (order 0), a tilt (order 1), an oval (order 2). This page trains such codes directly toward a face, from the dial alone up to orders 0–6, with an evolutionary search. A rough face needs order 1. A clean face, every feature cell dark and nothing else, needs order 3 and is complete by order 4 or 5. But it is a moment the tissue passes through, not a pattern it keeps. Adding the face's outline, the ring itself, does not work: the ring is dark only while the hold's imprint lasts, and the face forms long after. And the code does not draw the face. Its orders own the pattern while the ring is held, but by the moment the face appears no part of the pattern can be traced to any part of the code; the drawing is done by the extracellular field's feedback, without which not one cell goes dark.

The patterns

The best face at each order

Each code holds the 40 ring cells (the outer edge) at a mirror-symmetric profile, a₀ + a₁ cos θ + … + a_N cos Nθ, for the first 301 iterations, then releases them. Training searched the coefficients for the lowest balanced RMS against the target at any single iteration after release. Shown: the target; the tissue with no clamp; the best code of the earlier sweeps; and the best trained code of each size, at its best moment. All terms are defined under Methods.

Finding 1

A clean face needs order 3; orders 1 and 2 give a rough one, and more than 4 add nothing

The dial alone reaches 21.8 mV, by darkening the whole tissue just after release: half the error goes, but it is not a face. Adding a tilt (order 1) brings 17.1 mV and the first face: two eyes, a nose and a blob of a mouth (structural IoU 0.55, part score 5.3 of 8). That already beats the best code of the stored sweeps (19.4 mV). An oval (order 2) adds almost nothing (16.9 mV). Order 3 halves the error, to 8.9 mV (IoU 0.93, part score 7.97): only one cell too many, just above the nose. Orders 0–4 and 0–5 remove it (8.58 and 8.51 mV, IoU 1.0, part score 8.0). Orders 0–6 score 8.9 mV. They include every code of orders 0–5, so the larger code is harder to search, not less able. No random allowed code of any size comes near: their median is about 25.5 mV and their best 20.6–22.4 mV.

Finding 2

The face is a moment the tissue passes through, not a pattern it keeps

The score is the best single iteration after release, so training was free to find a code whose tissue passes through the face once. That is what it found. The best code (orders 0–5), run for 20,000 iterations, shows the face's shape (structural IoU ≥ 0.9) once, for 65 iterations (2,155–2,219), and never again. Every size from 3 up behaves the same: one visit of 55–119 iterations, between iterations 2,113 and 2,263. A hundred iterations either side, the score is 9.6 and 18.1 mV; five hundred either side it is back near 28 mV, worse than the tissue with no clamp at its best. The moment is also tuned finely to the code. Codes a step of about 0.007 in G_pol / G_ref away score a median of 16–20 mV at orders 3–6, and at most 8 of 32 stay within 1 mV of the best. As the earlier reports found, the tissue never settles after release. The code chooses the path it takes, and training found a path that passes through the face.

Finding 3 · the face with its outline

The outline and the face never appear together: the outline is the hold's afterglow, and it fades before the face forms

The original target also has an outline: all 40 ring cells dark, at −60 mV. Those are the very cells the code holds. So the ceiling was raised to the physical limit of 2, which lets a held value pass the bistable window (above 1.439 a lone cell has only its hyperpolarised state). The score now weighs three groups equally: the 14 feature cells, the 40 outline cells and the other 67. And because a dark ring right after release is only the hold's imprint, training ran twice: scoring from the release, and scoring from iteration 1,000, after that imprint has faded in every uniform hold. The result is a clean trade. Scored from the release, every best code has its moment between iterations 345 and 600, while the ring is still dark from the hold; the best (orders 0–5, 17.5 mV) has 34 of 40 ring cells dark but only part of the face (structural IoU 0.79). Scored from iteration 1,000, the full face forms (IoU 1.0 at orders 0–6, 21.4 mV), but the codes that form it have at most 8 ring cells dark at their moment. Run on for 20,000 iterations, none of the 14 best codes ever shows the face's shape with at least 90% of its ring dark.

Finding 4

By the time the face appears, no part of it belongs to any part of the code — and the machinery that undoes the code's parts is the machinery that draws the face

Ask which parts of the pattern belong to which part of the code, and the answer changes as the run goes on. Decompose the tissue by a spatial Fourier transform — a change of coordinates that assumes nothing about the model — and fit each mode's amplitude from the coefficients across 1,024 codes. While the ring is held, the code owns the bulk: for the first 16 iterations every mode carrying variance belongs to a single order, and excluding the clamped ring from the decomposition changes nothing (the interior alone is still at 0.998 by iteration 32). By the release the whole grid's owned share is 0.61, though the interior's own share is 0.22 — much of what is owned by then is the ring itself. After the release that grip decays and then collapses, between iterations 1,000 and 2,000 — before the face's features darken at 1,853. By the moment the face is scored, no mode is predictable well enough to belong to any order: the count of modes a quadratic fit explains half of falls from 98 to 0, and a nearest-neighbour fit does no better (R² 0.04). The code's influence has not vanished — of the interior's 80 modes, 44 still beat a shuffled-code null, and the average mode's fit explains 9% of its variance against 1% for shuffled codes — but it is spread far too thin to attribute to any part of the code. Spread, not destroyed: the best linear readout of the whole pattern at once, scored on held-out codes, still reaches 0.55 in this ensemble and 0.89 within a ±0.06 neighbourhood of the trained code (A13). What the face's moment lacks is not the code's influence but its divisibility. And the undoing is not a side effect. The extracellular field's feedback is the only thing driving the conductances once the clamp is gone. With it on, the map from code to pattern roughens steadily after the release, its exponent falling from 1.0 to 0.30 by the time the face is scored. Switch it off and that map stays perfectly smooth for the whole run, the tissue keeps the code's imprint (0.68 of the variance owned, unchanged from the release to iteration 2,999) — and never darkens a single cell. Hold the ring for the whole run instead and 0.31 stays owned, but only 57% of the face appears. The face needs the feedback, and it needs the code to be let go.

The storyline

The story so far, in plain terms

The ring code is a graphic equaliser — of the hold, not of the face. Order 0 is the volume knob: it makes the whole tissue darker or lighter but cannot place anything. Order 1 tilts treble against bass, top against bottom; with it the tissue already passes through a rough face, with eyes above and a blob below. Order 2 adds little. Order 3 is the slider that matters: with it the ring can be high along the top and at a single spot in the middle of the bottom edge, and low on the lower sides. Four numbers then suffice. Two more tidy the last stray cell. While the ring is held, the sliders really are separate: each order owns its own modes of the bulk pattern, and together they own nearly all of it.

But the sliders do not reach the face. Reading a role into each order — a₁ for the eyes, a₂ for the cheeks, a₃ for the mouth — and testing it by knockout supports none of the sixteen predictions those roles make: every effect stays inside what equal-sized random changes to the code produce. Nor is the face built from layers matching the code's orders. The reason shows up in the timing. The code's grip on the pattern decays after the release and collapses between iterations 1,000 and 2,000, and the face's features darken at 1,853 — after the grip is gone.

But the face is a cloud that looks like a face. After release the tissue drifts through one pattern after another and never settles. Training found the push that makes the clouds line up into a face at about iteration 2,190, for some 65 iterations. Then they drift on and never form it again. Change the push by a hair and the clouds line up at other times and in other shapes.

The outline is drawn in chalk. Holding the ring high enough darkens it, like a frame chalked around the picture. But the chalk washes off within a few hundred iterations, because once released the ring's own conductance relaxes. The face develops about 1,500 iterations later, on a bare wall. Training can have the frame or the face, never both.

What this means. A handful of harmonics is enough to write a face into this tissue, but only as a moment. Making it last would need a different target for training, such as the face held over a whole window, and may need more of the code, or a different hold. And the writing is indirect. The code does not draw the face: it sets a voltage pattern that the tissue then works on, and the work is done by the extracellular field's feedback, without which not one cell goes dark. By the time the face appears the code's grip is gone — its influence is still there, but spread so thin that no part of the pattern can be traced to any part of the code. Training is not composing a picture out of harmonics; it is searching for a push that happens to send this tissue through a face.

Appendix · supporting analyses

A1 · The trained codes

The best codes of sizes 3 to 6 agree closely. a₀ lies between 0.78 and 0.88, a₁ between 0.21 and 0.26, a₂ between 0.34 and 0.52 and a₃ between −0.32 and −0.15. The higher coefficients are small (|a₄|, |a₅|, |a₆| ≤ 0.12). The trained profile holds the top edge near 1.2, falls to about 0.2 on the lower sides, rises again to about 1.2 at the middle of the bottom edge, and stays near 0.44 at the bottom corners.

A2 · Library starts and random starts

Half the restarts started from the best codes already simulated (the library), half from a random allowed code. The library starts carried the order-3 code forward to orders 4–6, but random starts found the face too: at order 3 the best random start ended at 9.1 mV (population 64), against 8.9 mV for the best library start.

A3 · Features and background

Balanced RMS weighs the 14 feature cells and the other 107 cells equally. The tissue with no clamp gets the background nearly right (8.2 mV) and the features badly wrong (43.6 mV). The dial alone trades one for the other by darkening everything. The trained faces of order 3 and up bring both down together.

A4 · How sharply the score depends on the code

The landscape of best-moment scores is jagged. Around each trained code, a step of 0.01 of each coefficient's half range changes the score by several millivolts in either direction.

The near codes above move every coefficient at once, so they cannot say which order matters most. Here each coefficient of the best code is changed on its own. A change of d in aₙ moves ring cell k by d cos nθₖ, so by at most |d|. For n ≥ 1 that is an RMS change of d / √2 over the ring, against d for a₀. Many best codes touch both 0 and the ceiling, so a changed code may exceed 1.3 by up to the step; held values are clipped only at 0. The codes are the exact trained values: rounded to 4 decimals, the order 0–3 and 0–5 codes already score 12.5 and 10.2 mV instead of 8.9 and 8.5.

To see what those changes do to the tissue, the explorer below shows the stored pattern at each changed code's best moment. Pick a code size, then move one coefficient at a time, in steps of 0.0025 from −0.02 to +0.02 (moving one slider sets the others back to the trained value).

Why do tiny changes, that never move a ring cell across the bistable window, still turn the face into another pattern? Because the tissue's path forks, mostly more than a thousand iterations after release. The figure follows each changed code's tissue alongside the trained one and measures how far apart they are at every moment.

A5 · When the best moments fall

From order 3 up, every restart that ends within 1 mV of its size's best has its best moment between iterations 2,015 and 2,196. At orders 1 and 2 most fall between 1,879 and 1,983 (one at 2,969). Order 0's falls just after release, at iteration 309, while the tissue is still dark from the hold.

A7 · Training the face with its outline

Both windows used the same settings: population 64, 10 restarts per code size for orders 0–0 to 0–6, and two passes. Pass 1 started from a library of the stored sweeps and the face runs of the first half; pass 2 started from that library plus everything either window's pass 1 simulated. The two windows settle on different codes. Scored from the release, a₀ is 1.6–2.0 from order 1 up, so the whole ring is held above or near the top of the bistable window. Scored from iteration 1,000, a₀ is 1.3–1.6 and a₂ is negative (−0.25 to −0.56): a horizontal oval, the opposite of the face-only codes' vertical one.

A8 · Testing the orders' roles by knockout

Looking at the trained codes suggests a role for each order: a₁ gives the eyes a stronger push than the mouth, a₂ keeps the cheeks light, and a₃ separates the mouth from the nose. To test those roles causally, the predictions and their measures were written down before any simulation, and then the best code of orders 0–3 was run with every subset of a₁, a₂ and a₃ set to 0 (a₀ was never removed; zeroing it would test "no hold", not a role). Because A4 showed that even tiny changes can send the tissue down another branch, each knockout was compared with 20 random changes to a₁–a₃ that move the ring's held values by the same RMS amount. A role counts as supported only when the knockout moves its predicted measure beyond the controls' 5th–95th percentile, in the predicted direction.

Knockout alone asks whether the trained code relies on an order. Retraining asks whether the order is necessary: hold it at 0 and let the other coefficients adapt (population 64, 10 restarts). With a₃ held at 0 this is simply the orders 0–2 training of Finding 1: 16.9 mV, with the mouth merged into the nose.

A9 · Layers of the bulk and orders of the code

The code is built from orders, so the pattern it produces might be built from matching layers. Layer n is defined here as the exact discrete harmonic extension of the ring mode cos(nθ): the field that solves the four-neighbour discrete Laplace equation inside the ring when the ring is held at cos(nθ). This gives a sharp null. If the interior simply relaxed as passive diffusion from the held ring, the interior would be the harmonic extension of the ring's values, so moving coefficient ak by a small ε would move layer k and nothing else: the response matrix would be diagonal, with no remainder. This tissue is not passive — gap junctions are only one of its couplings, and the extracellular field's negative feedback is active throughout — so the question is not whether the null holds but how far from it the tissue sits, and when. Each coefficient was moved by ±ε for four sizes, the three single knockouts were run alongside, and at every probe iteration the interior response was fitted onto the layers.

P2 fails by reversing: larger perturbations look more diagonal, not less (0.16 at ε = 0.005 rising to 0.26 at ε = 0.15, measured at the last held iteration). The reason is the divergence of A4. By then a perturbation of 0.005 has been amplified into branch-scale differences — the same ε grows into about 16 mV of pattern change by iteration 2,173, a gain of roughly 3,300 — so the smallest probes measure which branch the tissue fell into rather than a local response. Amplification, not linearity, sets the floor on how small a probe can usefully be.

A10 · What the code owns

A9's layers were built from the ring's own modes, which ties the decomposition to a theory of how the boundary reaches the bulk. This appendix drops that tie. The pattern is decomposed by a spatial Fourier transform — the 2D cosine basis, the right Fourier family for a grid that does not wrap around — which is a complete orthonormal change of coordinates and assumes nothing whatever about the tissue's mechanics. A mode is then said to belong to an order when, across an ensemble of codes drawn from the feasible region, a quadratic fit on the coefficients explains at least half of that mode's variance and one order holds at least half of the first-order variance. Ownership here is a statistical statement about an ensemble, with no mechanism in it.

Note what the ensembles are. Unlike A8, A9 and A11, this appendix does not study the trained code. Each ensemble is 1,024 codes drawn at random from the feasible region and simulated exactly as in training; the trained code of orders 0–3 enters only by fixing the moments at which the patterns are compared, its own best moment of iteration 2,173 among them. The baseline ensemble carries four coefficients, matching that code's size, so ownership is measured over the same code space Finding 1 searched. Three further ensembles change one thing each: the ring is never released, the field's feedback is off, or the decomposition excludes the clamped ring. A fourth carries seven coefficients instead of four, orders 0–6, and exists only to test P4 — whether the higher orders that Finding 1 found add almost nothing to the face nonetheless own modes of their own. They do: a₄, a₅ and a₆ each own modes at the release. P4 fails at the other end of the code, because in that ensemble a₀ and a₂ own none.

A11 · The field's feedback, and letting the code go

A10 leaves a question. The code's grip on the pattern decays only after the ring is released, and the release is also when the tissue starts moving on its own. Both of those are the work of the same machinery. The extracellular field is computed from the charge distribution as the magnitude of the Coulomb field vector, averaged over each cell's neighbourhood out to four cells, and fed back to the polarising conductance with a gain of −1: a nonlocal negative feedback that responds to gradients rather than levels. It is the only thing driving the conductances once the clamp is gone. Turning it off therefore does not isolate a mixing term; it removes the tissue's dynamics altogether. The trained code was replayed in all four combinations of that switch and of releasing the ring.

A12 · How rough the map is

A10 found that once the face has formed, no smooth fit on the coefficients predicts any mode of the pattern. Two very different things would look like that. The map from code to pattern might carry no structure at all beyond the hold. Or it might be perfectly deterministic, as it must be in a model with no noise, but vary on a scale finer than the ensemble's spacing, so that a smooth fit has nothing to hold on to. Slices through code space were sampled at spacings from 0.039 down to 0.001 and turned into variograms: the mean squared difference between two outcomes against the distance between the codes that produced them. The answer is neither of the two. Every variogram is a straight line in log-log coordinates over the whole range measured — three decades of distance, straightness 0.95 to 0.99 — so the map has no characteristic scale at all. It is self-similar: zoom in anywhere and it looks equally rough. What such a map has instead of a correlation length is an exponent, the Hurst exponent, running from 0 for rough at every scale to 1 for smooth.

The roughening can be watched as it happens, and switched off. Sampling a slice at 0.004 and measuring the exponent at each moment, the map starts perfectly smooth and stays so while the ring is held, then roughens steadily once the tissue is on its own. With the extracellular field's feedback disabled it never roughens at all — the same switch that, in A11, costs the tissue every dark cell it has.

A13 · What survives: a mark that is spread out and local

A10's test can only see influence that sits in one mode: it asks whether a mode's amplitude follows one order. A mark spread thinly across many modes would fail that test while still being fully present. So the looser question was asked too. A rank-one reduced-rank regression finds the combination of modes the coefficients predict best — the best linear readout of the pattern that the code has, in any basis, not just the one chosen — and it is scored on codes held out of the fit, so a spread-out mark cannot hide from it and an overfitted one cannot pass.

Three ensembles are compared, and their shapes matter to what follows. The scattered one is the 1,024 random codes of A10, four coefficients varying over the whole feasible region, a median 0.111 apart. The two slices are flat cross-sections through the trained code: a₀ and a₃ frozen at its values (0.817 and −0.280), a₁ and a₂ swept on a 32 × 32 grid centred on its own (0.250, 0.434). One spans ±0.6 of that centre, the other ±0.06. Because the grid is the same size in both, the wider slice is also the coarser one — extent and spacing cannot be varied independently by changing the slice alone.

One number per code is hard to picture, so here is what it looks like. The readout gives two numbers per code. v is a fixed weighted sum of the interior pattern's coordinates in whichever basis is chosen — the cosine-mode amplitudes, or the principal-component scores — computed from the pattern alone. The direction is the one the coefficients explain best, found by regressing those coordinates on the coefficients and taking the leading direction of the fitted values. u is a weighted sum of the four coefficients, computed from the code alone: the combination of them that best predicts v by least squares. Both are then scaled to mean zero and unit spread. So v is what the pattern did along that direction and u is what the code says about it. The rescaling is worth keeping in mind when reading the scatter: the prediction itself varies less than v does — by exactly the correlation between them — so the line drawn through the cloud has that correlation as its slope rather than running at 45 degrees. The interior has 81 cells and each pattern's own interior mean is removed, leaving 80 usable directions in either basis; they are the same 80-dimensional space, but the coordinates are standardised one by one before the readout is fitted, and that step depends on the basis. It is the whole of why the two bases give different numbers — 0.55 in cosine modes, 0.62 in the ensemble's own components — for what is otherwise the same question. In the principal basis the readout is already at its ceiling by the leading 40 components, which cover 99.8% of the variance, so nothing there rests on the near-empty directions that standardising would otherwise blow up. The first panel shows the part of the ring code that u measures — the code's component along the readout's own direction, so it moves with u and with nothing else. The second shows what that one number predicts of the pattern: each cell's best linear prediction from u alone. The third shows the pattern the tissue actually reaches. Step through the ensemble in order of u and the first two panels glide, because both are functions of a single number, while the third jumps about. The gap between the second and third panels is what the readout leaves out — held out it scores 0.55, the same value A13 reports, on a fresh replay of the same ensemble.

A14 · Turning the feedback down

A11 and A12 leave the field's feedback doing two jobs at once: drawing the face and roughening the map from code to pattern. If those are the same property, turning the feedback down should trade one against the other. The trained code was replayed with fieldStrength scaled to 0, 0.25, 0.5 and 0.75 of its value, and a slice of 1,024 codes sampled 0.004 apart was replayed at each strength so the map's roughness could be measured. One thing to note before the numbers: a strength of 0 is not the same as the switch of A11. The field is still computed and still transduced — it simply carries no spatial information, so every cell is driven to the same conductance. The tissue then goes dark all over, which scores 100% of the face's cells and 67 cells that should have stayed light. Coverage is the wrong measure here; what improves with feedback is selectivity. The roughness column carries its own warning: a map can be smooth because it is informative, or because it is constant. At strength 0 every code in the slice ends at the same pattern, so the last column, the spread between the outcomes of two distant codes, is reported beside it.

A15 · Two things the result does not rest on

The moment. Every ensemble above is read at iteration 2,173, which is the trained code's own best moment and means nothing to the other 1,023 codes: their own best moments run from 498 to 2,899, with a median of 2,055, and only 73 of them peak within 50 iterations of 2,173. Two alternatives were run on the same replay. Averaging each code's pattern over iterations 2,000–2,400 removes the flicker of single iterations. Taking each code at its own best moment removes the difference in timing between codes altogether, comparing each where it comes closest to the face. Neither rescues the per-mode result.

The basis. The cosine modes are fixed by the grid, so all 1,024 patterns are decomposed in exactly the same modes and the readout uses one shared set of weights; nothing is fitted per code. The basis is complete, so no pattern is misrepresented by it — but it is not the basis the ensemble itself picks out. The patterns' own principal components need 7 to cover half the variance, 26 for 90% and 42 for 99%, and the leading ones do not sit on single cosine modes: the first is closest to the uniform mode at an overlap of 0.55, the third to a mode it matches at 0.35. That mismatch is exactly the room in which A10's per-mode test loses what A13's readout finds — influence spread over several cosine modes at once. It also places the surviving thread: the readout direction overlaps the first principal component by 0.86, and that component is the ensemble's overall-level direction, which is what the a₀-heavy weights of the readout already said.

So the whole of A10 was run again in that basis. The same ensemble, the same ownership test, but with the modes refitted at each probe iteration from the patterns themselves, so that every moment is read in the best basis available there. Both curves are in A10's figure and both bases in its mode map. While the ring is held the ensemble's own basis tells the story far more crisply: at the release three components carry 0.54 of the variance between them and each belongs to one order — the first (23.6% of the variance) to a₁ at R² 0.91, the second (15.7%) to a₀ at 0.79, the third (15.0%) to a₂ at 0.88 — where the cosine basis needed 29 modes to reach a comparable 0.61. The orders really do write into separate directions; the cosine modes were spreading each of them over many coordinates. And the collapse survives the change of basis. At the moment the face is scored the cosine basis finds nothing owned at all, the ensemble's own basis one component of eighty — the third, 8.7% of the variance, belonging to a₁ at R² 0.51, barely over the line. Two caveats keep that residue in proportion: the principal basis is fitted on the very patterns it is then tested on, so it is the friendliest basis these data admit, and the R² values on both sides are in-sample quadratic fits, unlike the held-out readout of A13.

A6 · Implementation

The code and its limits. A code of orders 0–N is N + 1 coefficients; the 40 held values are the cosine terms summed at each ring cell's angle. The ceiling, every held value between 0 and 1.3, is 80 linear conditions, so each coefficient's allowed range comes from linear programming. They cannot be read off by hand: from order 3 up, a₁ can reach ±0.75, beyond the ±0.65 of a tilt alone, because the higher orders can flatten the ends of the ring. The allowed codes fill only a small part of the box those ranges span (8% at orders 0–3, 3% at orders 0–4), so the search moves any code it draws outside them to the nearest allowed code, and charges the move against the score.

The search. CMA-ES, written out in learnBoundaryHarmonics11x11.py after Hansen's tutorial, with 16 codes per generation (64 in the second round) simulated as one batch of the model. One batch of 16 takes about 6 s for 3,000 iterations. The batched model reproduces the stored single-code sweeps to 10⁻¹² mV. Every code evaluated, with its score, best moment, pattern there and 2000–2999 average, is saved with its restart.

Starting points. The library holds every code already simulated that fits the code being trained: the stored sweeps' codes whose terms point straight up or down (read as signed coefficients), each with its top-to-bottom mirror image, and every code of earlier restarts, padded with zeros for the higher orders. The same rule serves any number of orders and any target.

Deviations from plan. Orders 5 and 6 and a second round with population 64 were added after the first round. They test whether order 4 was enough, and whether the step-like progress was the search's limit or the code's. In the first round, orders 0–2 ranked the library by each code's 2000–2999 average only, which left order 1's best code out of order 2's starting points; from order 3 on, trained codes were also ranked by their pattern at their best moment.

Methods

Terms

Lattice, cell
The tissue is an 11 × 11 square lattice of 121 cells, each coupled by gap junctions to its four nearest neighbours; the lattice does not wrap around at its edges.
Ring cells, interior cells
The 40 cells on the outer edge (rows 0 and 10, columns 0 and 10) are the ring cells; the code acts only on these. The other 81 are the interior cells.
Vmem
A cell's membrane voltage in millivolts (mV); lower is more hyperpolarised and drawn darker.
G_pol, G_ref
G_pol is the conductance of a cell's polarising ion channel; G_ref = 1 nS. Values are quoted as G_pol / G_ref. G_pol changes over time in this model.
Hold, release
During the hold, iterations 0–300, every ring cell's G_pol is overwritten on every iteration with its value in the code × G_ref. From iteration 301 (release) the ring cells follow the model's own rules again.
Ring code, order
The values held on the ring: a₀ + a₁ cos θ + a₂ cos 2θ + … + a_N cos Nθ, where θ is a ring cell's angle about the lattice centre, measured clockwise from straight up. Term n is order n; a code of "orders 0–N" has N + 1 coefficients a₀ … a_N. Order 0 is the dial (the same value on every ring cell). A positive a_n raises n evenly spaced points of the ring, one of them straight up; a negative a_n raises the n points between them.
Mirror symmetry, phase 0
Every term is a cosine measured from straight up (phase 0), with a coefficient of either sign. Such a code is the same on the left and right halves of the ring, as the face is, and every code with that symmetry can be written this way.
Ceiling, allowed codes
Every held value must lie between 0 and 1.3, the range in which the 301-iteration hold changed most smoothly in the dial sweep. For a code of orders 0–N this is 80 linear conditions on the coefficients, so the allowed codes fill a convex region (a polytope).
Target
−60 mV on the 14 feature cells (two 2 × 2 eyes, a three-cell nose and a three-cell mouth) and −5 mV on the other 107 cells, ring included. −5 mV is the most depolarised Vmem a cell can reach (the depolarising channel's reversal potential), so the target is reachable in principle.
Balanced RMS, score
Half the RMS (root-mean-square) error over the 14 feature cells plus half the RMS error over the other 107 cells, in mV, so the small feature set weighs as much as the rest. A code's score is the lowest balanced RMS at any single iteration from release to iteration 2,999 (its best moment). Lower is better.
Feature RMS, other RMS
The two halves of the balanced RMS, before halving.
Structural IoU
Of the interior cells below −34.6 mV (dark), the overlap with the 14 feature cells divided by their union: 1 for exactly the face's cells dark. −34.6 mV is the threshold of the earlier face reports.
Part score
Coverage + separation − 2 × spurious, at most 8. Coverage sums, over the four parts (each eye, the nose, the mouth), the share of the part's cells that are dark (0–4). Separation counts the covered parts that sit in a dark region of their own (0–4). Spurious is the share of the other interior cells that are dark.
No clamp
The same model and starting state with no hold at all, scored the same way.
Stored sweeps, best sweep code
The dial sweep and the Tilted Dial's order-1, order-2 and combined sweeps, all run earlier with the same hold. The best sweep code is the best of those rerun to seed training, scored as here.
Random allowed code
A code drawn uniformly from the allowed codes (see hit-and-run below).
Restart, generation, population
One restart is one independent training run. Each generation it simulates a population of 16 codes (population 64 in the second round) and moves its search toward the better ones. The name comes from multi-start optimisation, where a stalled search is restarted from a new point and the best result is kept. Here nothing is restarted: the restarts of one code size are separate runs, each from its own starting code and random seed, run side by side without seeing each other. Their only link is the library, from which a later code size or round can start. The code keeps the name (--restart, files order<N>_restart<rr>.npz).
Library start, random start
Half the restarts begin at one of the best codes already simulated (the library); the other half at a random allowed code.
Face with outline
The target of Finding 3 and A7: the face target plus its outline, the 40 ring cells, also at −60 mV (the original face target of the band-hold training). Every held value between 0 and 2, the physical range of G_pol / G_ref.
Three-group balanced RMS
For the face with outline: the mean of the RMS errors over the 14 feature cells, the 40 outline cells and the other 67 cells, so each group weighs a third.
Scoring window
The iterations over which the best moment is sought: from the release (iteration 301) or from iteration 1,000 on, in both cases to iteration 2,999.
Dark ring cells, face with outline shown
Ring cells below −34.6 mV, counted out of 40. A moment shows the face with its outline when its structural IoU is at least 0.9 and at least 90% of the ring cells are dark.
Bistable window
G_pol / G_ref from 0.802 to 1.439, where a lone cell has two resting states (about −50 and −10 mV); below it only the depolarised one, above it only the hyperpolarised one.
Spatial Fourier modes
The 2D cosine (DCT-II) basis of the 11 × 11 grid, φpq ∝ cos(πp(row+½)/11) cos(πq(col+½)/11): complete, orthonormal, and the Fourier family suited to a grid with no wrap-around. A pattern's mean is removed before decomposing. Chosen without reference to the model: it is a change of coordinates, not a claim about the tissue. (It happens to diagonalise the gap-junction Laplacian, but not the field's feedback, which is nonlocal and holds 96.8% of its energy off-diagonal in this basis, so no dynamical reading is attached to it.)
Harmonic extension (layer n)
The solution of the four-neighbour discrete Laplace equation on the 81 interior cells with the ring held at cos(nθ). The interior of a passive, purely diffusive tissue would equal the harmonic extension of the ring's values.
Mode ownership
Across an ensemble of codes drawn from the feasible region (ring values within [0.02, 1.98]), each mode's amplitude is fitted from the standardised coefficients by a quadratic model with interactions. A mode belongs to an order when that fit reaches R² ≥ 0.5 and the order holds at least half of the first-order variance, the latter measured as the variance of that order's own univariate part. ownedVarianceShare sums the ensemble variance of the owned modes. Rejection sampling correlates the coefficients by up to 0.25, so the split between orders is approximate; the time course is unchanged across R² cuts from 0.3 to 0.7 and share cuts from 0.4 to 0.6. Shuffling the codes against their patterns gives no owned modes at all and a mean R² of 0.013, so the measure has effectively no false-positive rate at this ensemble size. Repeating the baseline with 4,096 codes gives 0.67 owned at the release, 0.06 when the face appears and 0.00 at the scored moment, against 0.61, 0.06 and 0.00 at 1,024.
Best linear readout
The strongest linear relation between a code and its pattern, in any basis: the mode amplitudes are regressed on the standardised coefficients, the leading direction of the fitted values is taken as the readout's direction in pattern space, and that fixed direction is scored on codes held out of the fit (boundaryCodeUtilities.crossValidatedReadout, five folds). Only the four predictors are ever inverted. An earlier version used scikit-learn's CCA, whose NIPALS fit is unstable with many nearly collinear responses — on this ensemble it moved between 0.39 and 0.64 with the fold seed alone, and rose when noise was added — so every readout figure on this page comes from the estimator described here, which holds to within 0.02 across fold seeds, added noise and rounding.
Correlation length
From a slice through code space sampled on a grid: the mean squared difference between two codes' outcomes, binned by the distance between the codes, reaches half its plateau at this distance. Below it the map from code to outcome is smooth; above it two codes tell you little about each other.
Field feedback
The extracellular field is computed from the charge distribution by Coulomb's law as the magnitude of the field vector (fieldVector = True), averaged over each cell's neighbourhood out to fieldScreenSize = 4, and transduced to G_pol through a sigmoid with gain −1: nonlocal negative feedback responding to gradients rather than levels. fieldEnabled is True in every run of this page except where stated. Disabling it leaves G_pol undriven, so the tissue has no dynamics of its own once the clamp is released.
Knockout, size-matched control
A knockout sets chosen coefficients of the trained orders 0–3 code to 0 (never a₀). Its size is the RMS change it makes to the 40 held values; each of its 20 controls changes a₁–a₃ in a random direction by the same size. Held values are clipped to 0–2.
Knockout measures
Eye coverage (the share of the eyes' 8 cells that are dark), mouth and nose coverage (of their 3 cells each), eye minus mouth coverage, dark cheek cells (non-feature interior cells in columns 1–2 and 8–9), dark bridge cells (row 7, columns 4–6, between nose and mouth), whether the mouth's dark cells form a region with no nose cell, and all dark non-feature interior cells. Fixed, with the predictions, before any knockout was run (data/boundaryHarmonicKnockoutPredictions1888Hold301FaceMinus60Minus5.json).
Near codes
Codes a small random step from the best code: each coefficient moved by a Gaussian step of 0.01 of half its allowed range (about 0.007 in G_pol / G_ref), then moved back into the allowed codes if needed.
Within 1 mV of the best
An iteration at which the best code's balanced RMS is no more than 1 mV above its best score. A visit is a run of consecutive such iterations.

Procedures

Model and simulation
Checkpoint 1888's model and starting state (Vmem −9.2 mV, G_pol / G_ref 1.0, G_dep / G_ref 1.5 on every cell; gap-junction strength 0.05; bioelectric field on, screen size 4, transduction weight 1000, gain −1, bias 0.0005, time constant 10), with its own trained ring values discarded. Time step 0.01, 3,000 iterations per run. Many codes are simulated side by side as separate samples of one batched model; each follows exactly the trajectory of its own single run (checked against the stored sweeps to 10⁻¹² mV).
Coefficient ranges
The smallest and largest value of each coefficient over the allowed codes, by linear programming. The search works on each coefficient divided by half its range (scaled units).
Training (CMA-ES)
Covariance matrix adaptation evolution strategy: each generation draws a population from a Gaussian, keeps the better half, and moves the Gaussian's centre, width and shape toward them. Starting width 0.3 scaled units. A drawn code outside the allowed codes is simulated at the nearest allowed code, and its score is raised by 10 mV per scaled unit it had to move. A restart stops after 150 generations (100 in the second round), or earlier once the search width falls below 10⁻⁴ scaled units.
Library
Every code already simulated that is a phase-0 cosine series of the orders being trained: the stored sweeps' codes whose terms point straight up or down, and every code evaluated by earlier restarts, each also with its top-to-bottom mirror image (a_n → (−1)ⁿ a_n, pattern flipped), which the lattice's symmetry gives without simulation. Lower-order codes enter with their higher coefficients at 0. The 16 library codes whose stored pattern scores best are rerun and scored properly, and library restart r starts from the (r / 2)-th best. In the first round, orders 0–2 ranked the library by each code's 2000–2999 average only; from order 3 on, trained codes were also ranked by their stored best-moment pattern.
Rounds and schedule
First round: population 16, 20 restarts per code size, orders 0–N for N = 0 to 6 run one size after another so each could start from the codes of the sizes below. Second round: population 64, 10 restarts per size for N = 1 to 6, starting from everything the first round simulated.
Training the face with outline
As above, with population 64, 10 restarts per code size for orders 0–0 to 0–6, for each scoring window. Pass 1 started from the stored sweeps and the face runs; pass 2 also from everything both windows' pass 1 simulated. The library scores each run file's stored patterns as it reads them.
Knockout retraining
The trainer with one order held at 0 (--orders 0,2,3 or 0,1,3), population 64, 10 restarts, 100 generations, ceiling 1.3, starting from the face runs' library.
Random allowed codes
Hit-and-run sampling: from the centre of the allowed region, 500 steps each along a random direction to a uniformly chosen point of the chord through the region.
Checks of the best codes
The best code of each size rerun for 20,000 iterations and scored at every iteration; 32 near codes and 64 random allowed codes scored as in training.

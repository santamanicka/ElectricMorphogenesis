Sliding the orders: how the pattern changes

The relay below can only be run at a handful of ring codes, because each is an exact decomposition of a whole run. The pattern itself needs only the run, so it can be sampled densely: here every stop is a full replay of the model, the ring held to the code for the hold and released, with one order moved and the other two at the stripe code’s own values (a0 1.350, a1 0.001, a2 0.137). The tissue is shown at iteration 504, where the stripe code is read, and at each code’s own best moment. Whether the pattern moves smoothly, in steps or all at once is something to look at, not assume; nothing here was predicted or registered.

The relay loop, one ring code at a time, and what sliding the orders does to it

The movie follows one run. This draws the same exact relay as a single network, for any ring code, so that a code can be set beside its neighbours and the orders slid. The ten named blocks are the nodes (the ring’s four sides, the stripe in two halves, each flank in two halves); an arrow is the net field transfer between two blocks over a phase, read for every code at the stripe code’s own readout, iteration 504. There are two phases, not the face’s three: the hold (flood) and the release up to the readout (clear). The stripe is read before the interior’s conductance has turned, so there is no write phase. As in the movie’s block layouts, a block’s arrow is the net of its cells’ transfers: opposite transfers between the cells of two blocks cancel, and movement inside a block does not show. This whole section is exploratory: nothing in it was predicted or registered.
